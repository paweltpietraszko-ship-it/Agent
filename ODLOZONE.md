# ODLOZONE.md — rzeczy zauważone, świadomie odłożone

Backlog rzeczy, które ktoś zauważył, ale które NIE trafiają do BOARD.md ani do pamięci modeli — żeby nie
odżywały same w każdej rozmowie. Czyta się go tylko wtedy, gdy Paweł sam chce wrócić do tematu. Jeden wpis =
jedna sprawa, krótko, z datą i kontekstem wystarczającym, żeby podjąć temat bez odtwarzania rozmowy.

Format wpisu:

```
## [data] Tytuł

Krótki opis (2-4 zdania). Dlaczego odłożone. Gdzie szukać kontekstu (plik, task, commit).
```
